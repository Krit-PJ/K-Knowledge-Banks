K-Knowledge Bank

คลังความรู้ภาษาไทยที่ทุกข้อสรุปย้อนกลับถึงหลักฐานต้นฉบับได้ และทำงานได้แม้ปิด AI ทั้งหมด

สถานะ: กำลังพัฒนา (Phase 2) — ยังไม่มีข้อมูลความรู้เผยแพร่

หลักการ

หลักฐาน→แบบจำลอง→กฎตรวจสอบ→มนุษย์ตัดสิน
  • ทุกข้อสรุปต้องย้อนถึงไฟล์ต้นฉบับ เวอร์ชัน hash และตำแหน่งอ้างอิง (หน้า ตาราง แถว)
  • แยก Study / Report / Result / Finding / Claim ไม่นับรายงานซ้ำเป็นหลักฐานอิสระ
  • AI เป็นตัวช่วยเสริมเท่านั้น ไม่มีสิทธิ์อนุมัติหรือเผยแพร่ความรู้
  • ความรู้ที่เผยแพร่ต้องผ่านการอนุมัติของผู้ตรวจที่เป็นมนุษย์ ตรง revision ที่ตรวจจริง

หมวดหมู่ที่วางแผน

สรุปข่าวเทคโนโลยีในปัจจุบัน · ปรากฏการณ์สิ่งแวดล้อมและภัยพิบัติ · ความเคลื่อนไหวของประเทศมหาอำนาจ · พลังงาน
เทรนด์เทรนด์เทคโนโลยี · เทรนด์ AI · Skill ที่ได้รับความนิยมบน GitHub (ระบุตัวชี้วัด ช่วงเวลา และ snapshot เสมอ)

ความคืบหน้า

  1. Phase 1 — โครงสร้างพื้นฐานและ vertical slice แบบไม่ใช้ AI เสร็จแล้ว
  2. Phase 2 — รับข้อมูลเข้า หลักฐาน และการตรวจโดยมนุษย์ กำลังดำเนินการ
  3. Phase 3 — Knowledge Explorer, กราฟ และ Research Review
  4. Phase 4 — Hardening, AI เสริม และ MVP
